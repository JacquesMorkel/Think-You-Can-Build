# Think You Can Build

**Show how you solve business problems.**

Think You Can Build is a proposed live problem-solving show and graduate talent showcase. Graduates attempt the same computer-based business challenge in a facilitated session, making their reasoning, communication, and solution approach visible to reviewers and viewers.

## Links

- **Repository:** https://github.com/JacquesMorkel/Think-You-Can-Build
- **Live prototype:** https://jacquesmorkel.github.io/Think-You-Can-Build/

## Project status

This repository currently contains concept documentation, published via GitHub Pages at the live link above. There is no working web application or production deployment yet. The team is planning to build a small hackathon prototype and validate the format before developing the full platform.

## Planned technologies

The proposed website architecture is MERN:

- **MongoDB** for application data
- **Express.js** and **Node.js** for the backend
- **React** for the frontend

The MVP may use existing tools for calls and streaming (Teams or Google Meet, plus OBS or StreamYard) and YouTube for public video hosting. These choices are provisional and have not yet been implemented or tested. GPT, Claude, and AI page builders are being considered as development aids, not as runtime components of the product.

## Setup and running

There is no runnable application in this repository yet, so there are currently no install or run commands. Once the prototype is added, this section will list the required software, environment variables, installation steps, and development commands.

## Current limitations

- No application code or deployable prototype is included yet.
- No graduate or employer research, pilot, or user testing has been completed.
- No employer partners, challenge submissions, bounties, or internships are confirmed.
- Proposed cash rewards and job opportunities depend on future company agreements.
- Public streaming, consent, moderation, privacy, and intellectual property processes need to be prepared before a participant pilot.
- The project is not a job-placement guarantee and does not claim to solve unemployment.
